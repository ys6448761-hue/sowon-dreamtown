# SSOT-PROD-001 DreamTown StarSeed Guide

## 목적

DreamTown 별씨앗은 굿즈가 아니다.

소원의 감정을 현실에 남기는 상징물이다.

이 문서는 별씨앗의 제품 정의, 디자인 원칙, 버전 이력을 SSOT로 기록한다.

업체가 변경되어도 동일 품질로 재현 가능하게 한다.

---

## 기본 모델

**Hope Gold StarSeed**

- 형태: 별 모양 (5각)
- 기본 색상 방향: Hope Gold / 별빛 골드 (따뜻한 골드)
- 지양 색상: 형광 노랑

---

## 디자인 원칙

### DT 음각

- 위치: 뒷면 중앙보다 약간 아래
- 깊이: 0.6~0.8mm
- 방식: 음각 (표면을 파내는 방식)
- 유지 여부: 모든 버전에서 반드시 유지

### 형태

- 별 끝부분: 둥글게 처리 (날카롭지 않게)
- 이유: 착용 및 소지 안전성

### 색상 기준

- 형광 노랑 금지
- 따뜻한 골드 / 별빛 골드 지향
- 빛에 따라 은은하게 빛나는 마감 선호

---

## 버전 이력

### StarSeed V1.0

- 상태: 첫 샘플 / 프로토타입
- 색상: 형광 노랑
- DT 음각: 미적용
- 결과: 색상 부적합, 음각 미적용으로 방향 수정

### StarSeed V1.1

- 상태: 2차 샘플
- DT 음각: 적용
- 음각 위치: 뒷면 중앙보다 약간 아래
- 음각 깊이: 0.6~0.8mm
- 반응: 양호
- 미결 사항: 색상 개선 필요

### StarSeed V1.2

- 상태: 예정
- 개선 방향: Hope Gold / 별빛 골드 색상 적용
- 기준 문서: 본 SSOT

---

## 향후 컬렉션 확장 원칙

- 모든 신규 모델은 Hope Gold를 기준으로 확장한다
- DT 음각은 모든 모델에 유지한다
- 새 모델 추가 시 본 문서에 버전 이력을 추가한다
- 아이디어 → 샘플 → SSOT → 검수 → 본생산 순서를 반드시 따른다
