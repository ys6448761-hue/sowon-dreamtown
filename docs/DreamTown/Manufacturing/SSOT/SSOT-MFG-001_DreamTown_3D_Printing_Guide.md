# SSOT-MFG-001 DreamTown 3D Printing Guide

## 목적

DreamTown 별씨앗의 제작 공정을 SSOT로 기록한다.

3D 모델링부터 완제품 조립까지

동일 공정으로 재현 가능하도록 문서화한다.

---

## 제작 공정

### 1단계 — 3D 모델링

- 소프트웨어: (업체별 확인 후 기재)
- 기준 파일 형식: STL
- 디자인 기준: SSOT-PROD-001 참고
- 별 끝부분: 둥글게 처리
- DT 음각: 뒷면 중앙보다 약간 아래, 깊이 0.6~0.8mm
- 키링 연결부: 상단 포함 설계

### 2단계 — STL 생성

- 파일명 규칙: `StarSeed_V{버전}_{날짜}.stl`
- 저장 위치: 본 폴더 (`docs/DreamTown/Manufacturing/SSOT/`)
- 스케일 확인: 실제 사이즈 기준 (mm)

### 3단계 — 3D 프린팅

- 소재: (샘플 결과에 따라 업데이트)
- 레이어 두께: (업체 확인 후 기재)
- 서포트: 필요 여부 확인 후 기재
- 품질 기준: 표면 버가 없을 것, DT 음각이 선명할 것

### 4단계 — 후가공

#### 샌딩

- 목적: 표면 거칠기 제거
- 방법: 순차적 방수 사포 사용 (#400 → #800 → #1200)
- 기준: 손으로 만졌을 때 매끄러울 것

#### 도색 또는 소재 색상

- 방향 1: 소재 자체 색상 (골드 필라멘트 사용)
- 방향 2: 도색 적용 (희망 골드 / 별빛 골드)
- 형광 노랑 금지
- 최종 색상 결정: 샘플 검수 후 SSOT 업데이트

### 5단계 — 키링 연결부 조립

- 연결 방식: (업체 확인 후 기재)
- 내구성 기준: 잡아당겼을 때 분리되지 않을 것
- 마감 기준: 연결부 주변 버, 날카로운 부분 없을 것

## 제작 실패 기록

### V1.0 실패 원인

- 색상이 형광 노랑으로 DreamTown 감성과 불일치
- DT 음각 미적용으로 상징성 부재

### 교훈

- 색상 방향을 샘플 발주 전 SSOT에 명시해야 한다
- DT 음각은 최초 발주 시 반드시 포함해야 한다
