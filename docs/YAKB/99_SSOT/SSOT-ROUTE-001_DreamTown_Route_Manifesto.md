## 1. Purpose

DreamTown은 관광지가 아니라, 감정 회복 항로(Route)이며, 그 감정 품질은
SSOT로 유지된다.

## 2. Principles

1. DreamTown은 관광 프로젝트가 아니라 감정 회복 항로(Route) 프로젝트다.
2. 감정 품질은 사람이나 도구가 아니라 SSOT로 유지한다.
3. 장소는 캐릭터다 — 각 장소는 배경이 아니라 인격을 가진 존재로 취급한다.
4. 순서는 스토리다 — Route의 순서(sequence)는 임의 배열이 아니라 서사 구조다.
5. 모든 소원은 존중받아야 하며, 별은 소원이 이루어졌다는 증거가 아니라
   잊히지 않았다는 약속이다.

## 3. Applications

- Route 설계 (`docs/YAKB/02_SEEDS/Route/`)
- Journey 경험 설계 (`SSOT-JOURNEY-001`과의 연결)
- Star Trace 기록의 정서적 해석 (`SSOT-STARTRACE-001`과의 연결 — 별을
  "기록"이 아니라 "약속"으로 재해석할 여지가 있음, 충돌 아님)
- 마케팅/브랜드 카피, 랜딩 페이지, 캐릭터 대사

## 4. Example

- 좋은 예: "이 Route는 당신이 잊고 있던 마음을 다시 만나는 길입니다."
- 나쁜 예: "이 Route를 완료하면 배지를 드립니다." (성과·보상 프레임은 이
  철학과 충돌한다)
