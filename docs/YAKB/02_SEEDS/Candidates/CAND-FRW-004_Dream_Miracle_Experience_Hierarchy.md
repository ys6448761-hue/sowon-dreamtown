# CAND-FRW-004 — Dream · Miracle 경험 계층 프레임워크

## Purpose

Project Phoenix 전체 서비스가 하나의 철학으로 확장될 수 있도록,
Dream과 Miracle의 관계를 정의하고,
Miracle MVP를 중심으로 DreamTown, Shop, Learn 등 모든 서비스를
하나의 성장 구조로 통합한다.

## Core Definition

> **Dream은 소원이가 세상에서 살아가는 하나의 경험 세계이며,
> Miracle은 그 세계에서 발견하는 의미 있는 경험의 조각이다.**

Miracle MVP는 이러한 Miracle을 기록하여 별(소원이)의 성장을 관리하는
**Life Operating System**이다.

## Architecture

```
                    Miracle MVP
             (Life Operating System)

                      │

                 나의 별(소원이)

                      │

──────────────────────┼──────────────────────

               Dream Worlds

          DreamTown | DreamShop
          DreamLearn | DreamFestival
          DreamVolunteer | ...

                      │

              Experience (Miracles)

                      │

             별의 성장 (Growth)

                      │

             소원이의 성장
```

## Framework

### Miracle MVP

별의 모든 시간을 기록하고 성장시키는 운영체제.

모든 Dream의 경험은 결국 Miracle MVP로 돌아온다.

### Dream

소원이가 살아가는 하나의 큰 경험 세계(Experience World).

Dream은 콘텐츠가 아니라 **별이 살아가는 무대**이다.

| Dream | 설명 |
|---|---|
| DreamTown | 현실에서 처음으로 Dream을 경험하는 첫 번째 World (여행·지역·사람) |
| DreamShop | 지역 이야기와 기억을 품은 특산품·굿즈 세계 |
| DreamLearn | 배움을 통해 만나는 성장의 세계 |
| DreamFestival | 축제에서 발견하는 기억의 세계 |
| DreamVolunteer | 나눔을 통해 연결되는 세계 |

### Miracle

Dream 안에서 발견하는, 기억할 가치가 있는 경험.

| Miracle 형식 | 설명 |
|---|---|
| 기적영상 | 한 경험 조각을 영상으로 남긴 것 |
| 기적쇼츠 | 한순간의 기적을 짧게 전하는 것 |
| 기적웹툰 | 기적을 장면과 서사로 표현한 것 |
| 기적스토리북 | 여러 기적을 하나의 이야기로 엮은 것 |
| 기적사진 | 장소와 감정을 한 장에 담은 것 |
| 기적상품 | 지역의 이야기와 기억을 품은 특산품·굿즈 |
| 기적수업 | 배움을 통해 만난 성장의 조각 |

## Growth Flow

```
소원이
  ↓
Dream을 살아간다
  ↓
Miracle을 만난다
  ↓
Miracle이 기록된다
  ↓
별이 성장한다
  ↓
소원이가 성장한다
```

## DreamTown Definition

> **DreamTown은 소원이가 현실에서 처음으로 Dream을 경험하는 첫 번째 World이다.**

여행은 목적이 아니라 DreamTown이 제공하는 첫 번째 Experience이다.

DreamTown 안의 Miracle:
- 별빛항로 / 달빛항로 / 소망항로
- 지역 이야기 · 특산품
- 축제 · 사람과의 만남

## Naming Principles

| 용어 | 정의 |
|---|---|
| Dream | 경험 세계 — 별이 살아가는 무대 |
| Miracle | 경험 조각 — 기록 가능한 최소 의미 단위 |
| Star | 성장하는 존재 — 소원이의 별 |
| Miracle MVP | 별의 성장을 운영하는 Life Operating System |

## Platform Philosophy

> **Project Phoenix는 별이 세상을 살아가며 성장하는 구조를 만드는 프로젝트이다.**

Dream은 별이 살아가는 세계이며,
Miracle은 그 세계에서 발견하는 빛이다.
Miracle MVP는 그 빛을 기록하고, 별을 성장시키는 운영체제이다.

## Platform Layer Structure

```
Project Phoenix
      │
      ▼
Miracle MVP
(Life Operating System)
      │
      ▼
Dream (경험 세계)
      │
      ▼
Miracle (경험 조각)
      │
      ▼
Star Growth (소원이 성장)
```

이 구조는 여행, 쇼핑(지역 특산품 포함), 교육, 축제, 봉사 등
새로운 서비스가 추가되더라도 동일한 철학과 데이터 구조로 확장할 수 있는 기반이 된다.
