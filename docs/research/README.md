## Legacy Pending Review — PHX-004 ~ PHX-008

`PHX-004`, `PHX-005`, `PHX-006`, `PHX-007`, `PHX-008`은 이전 번호 체계(PHX-xxx)로 생성된 빈 폴더다.

R001~R003만 `R00x_Name` 체계로 이관되었고, PHX-004~008은 아래 사유로 **현 상태를 유지**한다.

- 지시된 저장 구조에 R004~R008 이관이 명시적으로 포함되지 않았다.
- Code는 연구를 해석하지 않으므로, 임의로 이름을 바꾸거나 내용을 채우지 않는다.
- 이관 여부와 새 이름(R004_Growth 등)은 별도 지시로 확정한다.

이 5개 폴더는 삭제 대상이 아니며, 검토 후 이관되거나 유지된다.
