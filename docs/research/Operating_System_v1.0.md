# Operating System v1.0 — Phoenix Research Institute

이 문서는 Constitution, PRM, Research Package Standard에 이미 정의된 원칙을 하나의 운영 체계로 요약한 스냅샷이다. 새로운 원칙을 추가하지 않는다.

## 운영 목적

10년, 100년 후의 새로운 연구자도 동일한 원칙으로 연구를 이어받을 수 있도록, 연구소의 운영 방식을 하나의 일관된 체계로 유지한다.

## 연구 흐름

PRM의 Research Cycle을 따른다.

```
Research
  ↓
Archive
  ↓
Comparative Matrix
  ↓
Common Pattern
  ↓
Foundation Candidate
  ↓
Cross Validation
  ↓
Research Freeze
  ↓
Code Save
  ↓
GitHub Verification
  ↓
Civilization Log
  ↓
Next Research
```

## 역할 분담

- 연구자: 연구를 수행하고 지식을 만든다.
- Code(Chief Knowledge Steward): 연구를 해석하지 않고 보존·구조화·버전 관리하며, 세대를 넘어 계승 가능하게 만든다.
- Constitution: Code와 연구자의 역할 경계를 정의한다.

## 저장 원칙

- 연구는 저장보다 먼저 완성되어야 한다(OP-010, Content Before Storage Rule).
- Code는 Research Package로 전달받은 후에만 저장한다.
- 연구자가 없는 연구는 Code가 작성하지 않는다.
- Confirmed SSOT로 승격되기 전까지 어떤 연구 문서도 실행(DreamTown 등)에 적용하지 않는다.

## 버전 관리 원칙

모든 표준 문서(PRM, Research Package Standard, Constitution, SSOT Template)는 OP-009 Living Methodology Rule을 따른다.

```
Freeze
  ↓
실사용
  ↓
개선사항 기록
  ↓
Proposal
  ↓
검증
  ↓
다음 버전 Freeze
```

표준은 사용 중 변경하지 않는다.

## Research Package 운영 방식

- 완료된 연구는 Research Package Standard v1.0의 13개 항목 구조(Metadata ~ Legacy Note)로 인계한다.
- Research Package는 연구를 재해석하거나 확장하지 않고, 이미 수행된 연구만 보존한다.
- 확인되지 않은 내용은 추측하지 않고 "자료 없음" 또는 "확인 불가"로 기록한다.
- 연구 결과의 진위는 각 Research 문서(R001~R008)가 책임진다.
