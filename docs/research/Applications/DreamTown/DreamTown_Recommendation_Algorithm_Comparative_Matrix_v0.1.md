# Comparative Matrix v0.1 — DreamTown Recommendation Algorithm Research

### Row 1. Core Algorithm Principle

YouTube: Push가 아니라 Pull. 시청자 만족 기반 추천.
DreamTown: 상품을 밀지 않고, 소원이의 현재 상태에 맞는 다음 경험을 끌어당겨 추천한다.

### Row 2. Primary Unit

YouTube: 영상 1개.
DreamTown: 소원 → 별 → 오늘 행동 → 항로 → 성장 기록.

### Row 3. Satisfaction Signal

YouTube: 끝까지 시청, 좋아요, 공유, 연쇄 시청, 재방문.
DreamTown: 오늘 재방문, 작은 행동 실행, 별 성장, 감정 변화, 다음 항로 진입, 나눔/공명.

### Row 4. Retention Loop

YouTube: 영상 → 다음 영상 → 재생목록 → 채널 재방문.
DreamTown: 소원 → 오늘 행동 → 별 성장 → 공명 → 여행/항로 → 새로운 소원.

### Row 5. Personalization Source

YouTube: 내 시청자가 보는 콘텐츠/채널/트렌드.
DreamTown: 소원이의 감정, 소원 유형, 실행률, 별 성장 단계, 항로 이력, 공명 반응.

### Row 6. Channel Architecture

YouTube: 쇼츠 → 롱폼 → 최종화면/고정댓글 → 재방문.
DreamTown: 무료 첫 항해 → 별 생성 → 성장 로그 → 추천 항로 → 유료 전환.

### Row 7. Content Strategy

YouTube: 유행 복제가 아니라 내 시청자 관점으로 재해석.
DreamTown: 일반 여행 복제가 아니라 "소원을 시작하러 가는 여행"으로 재해석.

### Row 8. Anti-Pattern

YouTube: 클릭bait, 기계적 AI 양산, 시청 시간 꼼수.
DreamTown: 단순 할인 여행, 기능 과다 설명, 감정 없는 상품 나열, 아우룸 주인공화.

### Row 9. DreamTown Direction

YouTube: 시청자 만족도를 높이는 콘텐츠 네트워크.
DreamTown: 소원이 만족도와 성장 지속성을 높이는 인생 항로 추천 엔진.
