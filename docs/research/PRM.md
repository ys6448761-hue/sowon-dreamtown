# PRM — Phoenix Research Methodology

PRM은 연구 방법론만 정리한다. Constitution은 `Constitution.md`를 따른다.

## Research Cycle

```
Research
  ↓
Archive
  ↓
Comparative Matrix
  ↓
Common Pattern
  ↓
Foundation Candidate
  ↓
Cross Validation
  ↓
Research Freeze
  ↓
Code Save
  ↓
GitHub Verification
  ↓
Civilization Log
  ↓
Next Research
```

## 원칙

- PRM은 살아있는 문서이다.
- PRM은 연구 결과가 아니다.
- PRM은 모든 R001~R008 연구에 적용되는 방법론이다.
- 연구와 저장은 분리한다.
- Freeze 후 저장한다.
- 저장 후 GitHub 검증한다.
- 검증 후 Civilization Log를 기록한다.
